# Steam Radar

Telegram-бот для мониторинга региональных цен Steam, скидок и бесплатных раздач.

## Возможности MVP

- отдельный выбор языка интерфейса и региона Steam;
- группированный выбор регионов Европы, Азии, Америки, Ближнего Востока, Африки и других стран;
- поиск игры по названию, App ID или ссылке Steam;
- условия «любая скидка», «скидка от X%» и «цена до X»;
- Free: 10 игр и проверка раз в сутки;
- Premium: 100 игр и проверка каждый час;
- собственная история изменения цен в PostgreSQL;
- немедленная загрузка и сохранение цены при добавлении игры;
- защита от повторных уведомлений;
- Redis для FSM, кэша Steam и координации;
- автоматическая загрузка Steam-раздач из GamerPower с указанием источника;
- стартовая фоновая синхронизация с Redis-lock от дублирования задач;
- расширенная защищённая админ-панель через `/admin`;
- оплата Premium через Telegram Stars;
- сравнение до 10 региональных цен с пересчётом через кэшированные валютные курсы;
- Premium-фильтры: новый/повторный минимум, любое снижение, минимальное снижение в сумме или процентах;
- единое уведомление для нескольких одновременно выполненных условий с кнопками Steam и удаления;
- группированный компактный выбор региона и часового пояса IANA;
- независимые Steam-регион, валюта ответа Steam и часовой пояс IANA;
- русский, английский, казахский и польский интерфейсы с русским fallback.

## Быстрый запуск

Требуются Python 3.12+, Docker и токен от `@BotFather`.

```powershell
Copy-Item .env.example .env
# Укажите BOT_TOKEN и свой Telegram ID в ADMIN_IDS

docker compose up -d
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
alembic upgrade head
steam-radar
```

При старте бот неблокирующе синхронизирует отслеживаемые цены и бесплатные предложения.
Для ручной диагностики источника раздач:

```powershell
.\.venv\Scripts\python.exe scripts\sync_giveaways.py
.\.venv\Scripts\python.exe scripts\sync_historical_lows.py
```

Для следующих запусков достаточно:

```powershell
docker compose up -d
.\.venv\Scripts\Activate.ps1
alembic upgrade head
steam-radar
```

## Настройки

Все настройки читаются из `.env`; пример находится в `.env.example`.

- `BOT_TOKEN` — токен Telegram-бота;
- `DATABASE_URL` — async SQLAlchemy URL PostgreSQL;
- `REDIS_URL` — адрес Redis;
- `ADMIN_IDS` — Telegram ID администраторов через запятую;
- `FREE_CHECK_HOURS` / `PREMIUM_CHECK_HOURS` — интервалы тарифов.
- `APP_TIMEZONE` — часовой пояс служебных дат и времени обновления раздач, например `Europe/Warsaw`.
- `DEAL_BROADCAST_PRICE_MAX_AGE_HOURS` — максимальный возраст цены для административной подборки, по умолчанию 26 часов.
- `DEAL_BROADCAST_BATCH_SIZE` — размер пакета пользователей персональной рассылки, по умолчанию 50.
- `DEAL_BROADCAST_MESSAGES_PER_SECOND` — ограничение скорости рассылки, по умолчанию 20 сообщений/с.

Курсы валют загружаются централизованно из открытого endpoint ExchangeRate-API. Свежий кэш
используется 6 часов; при сбое допускается последний успешно сохранённый набор не старше 72 часов,
причём интерфейс явно помечает устаревшие курсы. Денежные вычисления выполняются через `Decimal`.

## Миграции после обновления

```powershell
.\.venv\Scripts\alembic.exe upgrade head
.\.venv\Scripts\alembic.exe current
.\.venv\Scripts\alembic.exe check
```

Миграция `0008` добавляет настройки сравнения, независимые ежедневный и еженедельный дайджесты,
отображаемое имя/источник Premium и журнал административных изменений подписки. Старые данные и
активные подписки сохраняются.

Миграция `0009` добавляет расширенные условия Premium-уведомлений и Steam App ID для уведомлений,
отложенных на время тихих часов. Благодаря этому отложенные сообщения получают те же кнопки
«Открыть в Steam» и «Закрыть», что и мгновенные.

Миграции `0010` и `0011` добавляют устойчивые запуски персональной рассылки скидок, статусы
получателей, сохранённые страницы, защиту от параллельного запуска и тип клавиатуры для сообщений,
отложенных из-за тихих часов.

## Управление ботом в Telegram

Командные сообщения пользователя автоматически удаляются из чата. Большинство экранов бот
обновляет редактированием одного сообщения, поэтому история чата не разрастается.

### Пользовательские команды

| Команда | Назначение |
|---|---|
| `/start` | Регистрация и первоначальный выбор языка и региона. Для зарегистрированного пользователя открывает главное меню. |
| `/menu` | Открыть главное пользовательское меню. Также помогает вернуться в интерфейс после устаревшей кнопки. |
| `/games` | Показать список отслеживаемых игр. Каждая игра открывается отдельной интерактивной кнопкой. |
| `/watch` | Запустить поиск и добавление новой игры по названию, Steam App ID или ссылке Steam. |
| `/deals` | Показать обнаруженные скидки среди отслеживаемых игр. |
| `/free` | Открыть актуальные временные бесплатные раздачи. Постоянные free-to-play игры отделяются от раздач. |
| `/premium` | Показать тариф Premium, варианты оплаты или сведения об активной подписке и историю платежей. |
| `/settings` | Открыть профиль: язык, регион, валюта, тариф, тихие часы и режим дайджеста. |
| `/help` | Показать встроенную справку и перечень команд. |
| `/terms` | Показать условия использования и предупреждение об информационном характере цен. |
| `/admin` | Открыть админ-панель. Доступно только Telegram ID из `ADMIN_IDS`. |

### Главное меню

- **Мои игры** — список правил отслеживания и добавление новой игры.
- **Найти игру** — поиск Steam-игры и создание условия отслеживания.
- **Скидки** — последние скидки среди игр пользователя.
- **Бесплатно** — подтверждённые раздачи и время последнего обновления.
- **Premium** — оформление или управление действующей подпиской.
- **Профиль** — язык, регион/валюта, тихие часы и дайджест.

### Управление отслеживаемой игрой

В карточке игры доступны:

- **Изменить скидку** — уведомлять при достижении заданного процента от 1 до 100;
- **Изменить цену** — уведомлять, когда цена станет не выше указанной суммы;
- **Уведомления: включены/выключены** — переключить уведомления только для этой игры;
- **Открыть в Steam** — перейти на официальную страницу магазина;
- **Удалить** — полностью удалить правило отслеживания;
- **К списку** — вернуться к отслеживаемым играм;
- **В меню** — вернуться в главное меню;
- **Повторить загрузку цены** — появляется, если Steam временно не вернул региональную цену.

Лимиты проверяются сервером: Free позволяет до 10 активных правил, Premium — до 100.
Повторный callback не позволяет обойти ограничение.

### Профиль и уведомления

- **Изменить регион/валюту** — меняет регион Steam и сразу запрашивает цены заново;
- **Изменить язык** — переключает русский, английский или казахский интерфейс;
- **Тихие часы** — переключает режим `23:00–08:00` в часовом поясе пользователя;
- **Дайджест** — последовательно переключает режимы: выключен → ежедневный → еженедельный;
- **В меню** — выход из профиля.

Во время тихих часов уведомления сохраняются в PostgreSQL и отправляются после их окончания.
Перезапуск приложения не удаляет очередь.

### Premium и Telegram Stars

Free-пользователь может выбрать подписку на 1, 3 или 12 месяцев. Активный Premium-экран показывает:

- дату начала и окончания;
- оставшееся время;
- лимит игр;
- частоту проверки цен;
- историю платежей.

Premium выдаётся только после подтверждённого Telegram `successful_payment`. Повторная обработка
одного `telegram_charge_id` запрещена. Для бесплатной проверки полного Stars-сценария нужны отдельные
тестовые аккаунт и бот: локальный флаг не превращает обычный Telegram-токен в тестовый.

### Административная панель

Права проверяются на каждом admin handler и callback, а не только при отображении кнопки.

- **Запустить синхронизацию** — фоновое обновление цен и раздач;
- **Обновить конкретную игру** — запросить Steam App ID и обновить региональные цены;
- **Последние пользователи** — показать последние регистрации;
- **Последние ошибки** — вывести сохранённые системные ошибки;
- **Создать рассылку** — подготовить сообщение, показать предпросмотр и запросить подтверждение;
- **Выдать тест Premium** — дать текущему администратору Premium на 24 часа без платежа;
- **Добавить раздачу** — вручную добавить подтверждённую раздачу по HTTPS-ссылке;
- **Обновить панель** — заново загрузить статистику и состояния сервисов;
- **Выйти в меню** — вернуться в обычный пользовательский интерфейс.

Рассылка не начинается одним нажатием: сначала вводится текст, затем показывается предпросмотр,
после чего требуется отдельное подтверждение. Telegram rate limit обрабатывается автоматически.

## Архитектура

`bot` содержит Telegram UI и FSM, `services` — Steam-провайдер и мониторинг,
`db` — модели и репозитории, `scheduler` запускает периодические задания. Важные данные
хранятся в PostgreSQL, Redis используется только для временного состояния и кэша.

Магазинные JSON-эндпоинты Steam изолированы в `SteamProvider`, поскольку Valve не гарантирует
их стабильность как полноценного публичного контракта. Это позволяет заменить источник без
переписывания бизнес-логики.

### Исторические минимумы IsThereAnyDeal

Steam Radar хранит собственный минимум с начала наблюдения независимо от внешних сервисов.
Дополнительно можно подключить официальный IsThereAnyDeal API: зарегистрируйте приложение на
`https://isthereanydeal.com/apps/` и добавьте полученный секрет только в `.env`:

```env
ITAD_API_KEY=replace_me
ITAD_SYNC_HOURS=24
```

После перезапуска бот пакетно сопоставит Steam App ID с ITAD и раз в сутки сохранит два разных
значения по каждому используемому региону: исторический минимум именно в Steam и минимум среди
всех поддерживаемых магазинов. В уведомлениях Steam-минимум отображается только при совпадении
валюты. Без ключа интеграция отключена и обычный мониторинг продолжает работать.
# Production и эксплуатация

## Development

```powershell
docker compose up -d
.\.venv\Scripts\alembic.exe upgrade head
.\.venv\Scripts\steam-radar.exe
```

Для безопасной проверки интерфейса оплаты используйте отдельного бота и аккаунт в тестовой среде
Telegram, затем установите `APP_ENV=development` и `TELEGRAM_PAYMENT_TEST_MODE=true`. При этом бот
подключается к официальному Test Bot API (`/bot<token>/test/...`), поэтому токен должен быть создан
через @BotFather именно в тестовой среде. Обычный токен Telegram с этим режимом не заработает.
Не включайте тестовый режим с боевым токеном.
Бот выдаёт Premium только после Telegram `successful_payment`; одного callback недостаточно.
Комбинация `APP_ENV=production` и тестовых платежей блокируется при старте.

## Production Docker

Скопируйте `.env.production.example` в `.env.production`, замените все значения `replace_me`, затем:

```bash
docker compose -f docker-compose.prod.yml build
docker compose -f docker-compose.prod.yml run --rm app alembic upgrade head
docker compose -f docker-compose.prod.yml up -d
docker compose -f docker-compose.prod.yml ps
```

Healthcheck доступен на `GET http://127.0.0.1:8080/health`. Он проверяет PostgreSQL, Redis и
планировщик, не возвращая строки подключения или секреты. Redis-lock с TTL не позволяет двум
экземплярам начать polling одного токена.

## Backup и restore

Ручной backup на хосте с установленным `pg_dump`:

```powershell
.\.venv\Scripts\python.exe scripts\backup.py
```

В Docker:

```bash
docker compose -f docker-compose.prod.yml exec app python scripts/backup.py
```

Для восстановления сначала остановите приложение и выполните вручную (restore никогда не запускается автоматически):

```bash
pg_restore --clean --if-exists --no-owner --dbname "$DATABASE_URL" backups/steam_radar_DATE.dump
```

Перед restore обязательно создайте свежий backup. Retention управляется `BACKUP_RETENTION_DAYS`.
